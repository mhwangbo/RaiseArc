RaiseArc helps you make a raising game in Unity. Define a character, activities, conditions, effects, events, dialogue, plans, and endings in the editor. Connect your own UI Toolkit screen to official game data and commands. The optional MCP adapter is separate from normal authoring and play.

**Documentation target:** `0.1.0-preview.0`, verified on Unity 6000.6.0f1 for Windows. A clean consumer project installed the pinned Git package, created and edited a game, and built a Windows player. Representative play, dialogue, save/load, analysis, optional MCP transport, and copy-first migration checks passed. This is an early preview with [specific limits](known-limits.md), not a promise that every old game or content combination works.

Start with [installation](installation.md), then [make a first game](first-game.md). If you already have an old `Assets/PrincessStudio` installation, read [migration](migration.md) first.
