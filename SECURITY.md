# Security

For a suspected vulnerability, use **Security → Report a vulnerability** on GitHub so details are not posted publicly. If that option is unavailable, contact the repository owner through a private channel before disclosing details in an issue. The supported preview is `0.1.0-preview.0`; no response time is promised.

The optional MCP adapter gives a local client access to the selected Unity project's authoring commands. Enable it only for a client you trust. It is not a sandbox for installed Unity extensions.
