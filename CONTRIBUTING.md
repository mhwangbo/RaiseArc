# Contributing

The package is an early public preview. Open an issue before a substantial change. Keep runtime independent of Unity Editor graph code, and send Studio, Graph, and MCP edits through the revision-checked Authoring API.

New public names use RaiseArc. Legacy `PrincessStudio.*` identifiers are retained for serialized compatibility until a migration test covers the affected assets, saves, and protocols. Include a focused regression check for changes to save, plan, analysis, or migration behavior.
