RaiseArc는 Unity에서 육성게임을 만드는 도구입니다. 활동, 조건, 효과, 사건, 대화, 계획, 엔딩을 편집하고 UI Toolkit 화면을 공식 데이터와 명령에 연결합니다. MCP는 선택 기능입니다.

**대상 버전:** 비공개 `0.1.0-preview.0` 후보, Windows의 Unity 6000.6.0f1. 새 로컬 개발 프로젝트에서 패키지 컴파일과 Native UI 세 종류 및 Composer 장면 생성을 확인했습니다. Git 설치, 실제 플레이, 실행 파일, 옛 프로젝트 이전은 아직 확인 중입니다.

[설치](installation.md)부터 시작하세요. 기존 `Assets/PrincessStudio` 사용자는 [이전 안내](migration.md)를 먼저 읽으세요.
