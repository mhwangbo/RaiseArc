id: known-limits
title: 프리뷰 상태
---

비공개 `0.1.0-preview.0` 후보는 새 Unity 6000.6.0f1 로컬 프로젝트에서 컴파일됐고 Native UI·월간·다음 날·Composer 장면을 생성했습니다. Git 설치, 실제 플레이, Windows 실행, 옛 프로젝트·세이브 이전은 아직 통과하지 않았습니다.

전체 자체 코드·이력·에셋 감사, 일부 옛 `Assets/PrincessStudio` 경로 이전, 폰트 바이너리 출처 확인, MCP 실제 전송 검사가 남았습니다. 세 튜토리얼을 분리 패키지나 실제 초보자가 끝까지 따라간 평가도 없습니다.

MCP는 선택 사항이며 현재 Windows Editor용입니다. UI Toolkit 표준 요소 연결이 기본 경로이고 새로운 게임 명령은 코드 확장이 필요합니다. 분석은 표시된 예산·미지원 경계 안에서만 해석하세요.
