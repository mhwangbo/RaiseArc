id: known-limits
title: 프리뷰 상태
---

`0.1.0-preview.0` 패키지는 Unity 6000.6.0f1 Windows의 새 프로젝트에 고정 Git 커밋으로 설치했습니다. 공개 대상 자체 C#/Python 소스 136개 검토 기록, EditMode 74/74, 대표 Windows 플레이와 두 줄 대사 후 게임 복귀, MCP 전송, 1회 분석 UI 비교, 옛 프로젝트 복사본 이전 근거가 있습니다. 이는 모든 콘텐츠 조합의 보증이 아닙니다.

프리뷰 제한:

- 검증한 환경은 Unity 6000.6.0f1 Windows Editor와 실행 파일입니다. 다른 버전·플랫폼은 미확인입니다.
- 옛 Assets 설치를 올리기 전에 변경 사항을 저장하고 Unity를 종료한 뒤 프로젝트를 백업해 복사본에서 이전하세요. 옛 assembly와 새 패키지를 함께 설치하지 마세요. 저장하지 않은 Editor 메모리 상태는 자동 승계 대상이 아닙니다.
- 검사한 옛 프로젝트 복사본은 글꼴·Addressables 참조에 개별 수정이 필요했습니다. 다른 사용자 에셋과 UI는 각각 확인해야 합니다. 원본 게임과 세이브는 보존했습니다.
- 대표 게임 및 작은 분석 표본은 모든 사건·계획·난수·세이브 조합을 포함하지 않습니다. 콘텐츠 변경 후 보존 결과 비교를 정확 재현으로 해석하지 마세요.
- 튜토리얼은 설치본에서 에이전트가 검토했고 Unity 입력 일부는 사람이 도왔습니다. 실제 초보자의 장기 사용성 평가는 미수행입니다.

MCP는 선택 사항이며 현재 Windows Editor용입니다. UI Toolkit 표준 요소 연결이 기본 경로이고 새로운 게임 명령은 코드 확장이 필요합니다. 분석은 표시된 예산·미지원 경계 안에서만 해석하세요.
