id: assets-localization
title: 이미지·언어·음성
---

Studio에서 언어별 문장을 작성합니다. 표시값은 안정적인 키와 별도의 번역을 갖습니다. 사용할 언어, 기본 언어, 대체 언어를 정한 뒤 **Sync Unity tables**를 실행합니다. 기존 저장 자료 호환성을 위해 테이블 이름의 `Princess.` 접두사는 남아 있습니다. CSV 형식은 `key,locale,text,draft`입니다.

사용 권리가 있는 이미지와 AudioClip을 게임 프로젝트의 `Assets`에 가져온 뒤 해당 언어의 에셋 GUID를 연결하세요. UI Toolkit Image는 캐릭터·배경·활동 이미지를 표시할 수 있습니다. 샘플 생성기는 사용자가 교체할 수 있는 단색 기본 이미지를 게임 폴더에 만듭니다. 대사 음성은 선택 사항이며 `SetDialogueVoice`에 빈 GUID를 주면 해당 언어에서는 소리가 나지 않습니다.

후보 템플릿의 한국어 글꼴에는 OFL 고지가 들어 있지만 바이너리 출처 재확인은 공개 전 필수입니다. 다른 언어는 사용 권리가 있는 글꼴을 준비하세요. 배포 전 Addressables 빌드와 Windows 실행 파일에서 실제 글자·이미지·음성을 확인해야 합니다.
